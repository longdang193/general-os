# Historical Plans

Dated files under `docs/superpowers/plans/**` are historical execution
artifacts. They may explain prior decisions and preserve past evidence, but
they are not current governance and never override `AGENTS.md`, active skills
or rules, repository contracts, or current Git state.

Use current source, tests, contracts, active guidance, and Git as the authority
for present work. Do not treat historical plan steps, terminology, runtime
identities, or completion claims as current instructions.
